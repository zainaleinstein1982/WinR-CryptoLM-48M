# CryptoLM-48M: Foundational LLM Chat Application & Wiki Skill

> **Global Innovation Build Challenge (GIBC) V2 — Track 01: TECH (Foundational LLM Development)**
> Built from scratch. No pretrained weights, no distillation, no hosted inference API as the model.

---

## 🚀 One-Paragraph Pitch
CryptoLM-48M is a 48,156,928-parameter decoder-only transformer language model trained entirely from scratch on a curated 12B token corpus of Solidity, Rust, cryptographic primitives, and technical computer science textbooks. Featuring a production-grade chat interface mirroring DeepSeek's UI and an integrated **Wiki Skill (RAG)** inspired by `llm_wiki`, CryptoLM-48M provides real-time streaming inference and grounded knowledge retrieval for secure smart contract and on-device code development within a strict ≤50M parameter budget.

---

## 📚 Wiki Skill & RAG Pipeline
- **External Tool Architecture**: The wiki knowledge base is stored locally in the `wiki/` directory as Markdown documents with a JSON link index (`wiki/index.json`). 
- **Parameter Independence**: The wiki skill operates entirely as an inference-time Retrieval-Augmented Generation (RAG) module and **does NOT add trainable parameters** to the language model. The model remains strictly ≤50,000,000 parameters.
- **Two-Step Ingestion & Hybrid Search**: Documents are ingested, chunked, and indexed via FlexSearch/hybrid keyword matching. When a user asks a question (or uses the `/wiki` chat command), relevant wiki pages are retrieved and injected into the prompt context.
- **Graph Visualization**: An interactive link graph visualizes connections between wiki documents.

## 🛠️ Setup & Installation

### Prerequisites
- Node.js 18+ & npm
- Python 3.10+ with PyTorch 2.4+
- 1x NVIDIA RTX 4090 (24GB VRAM) for training / inference

### 1. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 2. Start Express Proxy & Vite Development Server
\`\`\`bash
npm run server &  # Starts Express proxy & Wiki API on port 3001
npm run dev       # Starts Vite React client on port 3000
\`\`\`

### 3. Start Python FastAPI Model Server (Local Inference)
\`\`\`python
python server/model_server.py
\`\`\`
